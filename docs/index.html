How it works

Drag

Hold an item and start the drag away from buildings that can take items. Concrete, pipes, and solar panels are fine. Then sweep across buildings. Right mouse offers half instead.

Ctrl + Left mouse

Dump

Send excess ores, intermediates, science packs and trash-slot items to nearby compatible buildings.

Shift + C

Both actions use your selected distribution mode. Items that cannot be placed stay at their source.

In Even Distribute, Drag leaves a full building’s rejected share with you. Dump can redistribute rejected shares among eligible destinations. Drag can do the same when distributing spoilable items.
Balance Inventory counts what is already in each building and aims for even final stock. It can also redistribute matching stock from ordinary machines and chests. Existing stock in turrets and vehicles stays in place during balancing.

Changes since original

Bio items

In Advanced, choose Spoiled first (default) or Fresh first. One Drag can work through up to three freshness groups. Dump offers one group per item, starting at the selected end.

  1. Mostly spoiled
  2. Medium freshness
  3. Fresh

Freshness is averaged by item count within the active group. Each group is averaged separately when it is distributed.

Nutrients can fill a Biochamber’s fuel and recipe input. If a Biochamber in your Drag can use both, choose where to send them. Dump can put Bioflux in matching recipe inputs and Nutrients in the fuel slot in the same action. Fuel limits apply.

Initial spoilage preservation contributed by FallenPaladin.

Ammo

Dump ammo is enabled by default. In Advanced, choose Low tier ammo first (default) or High tier ammo first. This sets the Dump order within each ammo family, including magazines, cannon shells, and rockets. Within a magazine type, Dump uses partly spent magazines first.

Drag can move multiple stacks in one action with Inventory selected under Distribute items from. The ammo limit applies per destination. Dump → Ignore requests keeps 100 of each equipped ammo type and quality across weapon slots, inventory and cursor. Respect requests uses the personal request maximum instead.

Atomic bombs can go to compatible turrets through Drag. Dump can send them to chests.

Ammo and personal requests

You have 1,000 piercing magazines total, with 980 in inventory and 20 equipped. Your request maximum is 600. The 48 empty gun turrets have a limit of 0.2 stacks (20 magazines each).

Fuel

Dump refills boilers and other compatible burners up to the configured fuel limit. In Advanced, choose Low fuel value first (default) or High fuel value first.

With Respect requests, Dump keeps the fuel you’ve requested in personal logistics. Fuel in trash slots is available in either mode.

Quality

Drag supports all qualities. Dump handles Normal items by default. Enable Dump higher-quality items (Beta) in the in-game settings to include higher qualities. This can move valuable items from your inventory. Hover over the in-game ⓘ for details.

Dragging modules

Drag opens the module popup when a building accepts the module in both its input slot and its module slot.

Dragging placeable items

Drag can distribute placeable items such as transport belts to machines that use them as recipe ingredients.

Protected destinations

Recycler and heating tower
Drag first. Dump only tops up an input or fuel inventory that already contains items.
Nuclear and fusion reactors
Drag only, even when already supplied.

Community fixes

Multiplayer Inventory Cleanup

When another player joins the same force, Inventory Cleanup reuses the shared default logistic filters. This preserves any edits and avoids the duplicate filter error that could crash the server.

Fix contributed by Deadpoolweid · Pull request #1

Settings, compatibility and fixes

Settings tweaks
  • Added more help icons.
Compatibility updates
  • With GUI Unifyer, the shared mod button opens the settings window fully expanded.
  • Space Age and GUI Unifyer are recommended dependencies.
  • Other Even Distribution variants are marked as incompatible.
  • Fixed Modlist UI requesting outdated thumbnail dimensions.
Inherited overhaul compatibility

Inherited Dump defaults take effect when matching items or groups exist.

  • Bob’s Mods
  • Angel’s Mods
  • Pyanodons
  • Space Exploration
  • Industrial Revolution
  • DyTech
  • ScienceCostTweaker

These defaults have not been retested with current overhaul versions. The original mod already marked DyTech and Pyanodons as untested.

Reliability fixes
  • Updated fuel handling for Factorio 2.1, including multiple fuel categories.
  • Restored the original allocation rules for full destinations, existing stock, remainders and rounding.
  • Fixed item loss when a native transfer automatically refills the cursor from the inventory.
  • Preserve quality, remaining shots, durability and health. Spoilable items follow the freshness order selected in Advanced.
  • Handle partial transfers and returns without dropping rejected items on the ground.
  • Safely switch between dragged items and qualities, and restore items after sorting or changes to available inventory space.
  • Improved save/load and update handling. Import saved preferences and ignored buildings when replacing the original mod. Update defaults while keeping saved preferences.
  • Corrected the position of distribution markers on Spidertrons.
  • Recognize possible recipe outputs even when the minimum yield is zero.
Performance updates
  • Reduced repeated inventory scans and temporary-inventory creation during selection changes.
  • More targeted cleanup of temporary transfer backups.
  • Faster target lookups while preserving distribution order.
